# MhExpense Native Android

This folder contains a native Android version of your income/expense app with offline SQLite storage.

## Features
- Add income and expenses
- Track categories
- Show total balance, income and expense
- Recent transactions list
- Fully offline using SQLite
- Android native UI

## Open in Android Studio
1. Open Android Studio.
2. Select `Open an existing project`.
3. Choose the `native-android` folder.
4. Let Gradle sync and build.

## Notes
The app is designed for local-only use, so it works without internet access after installation.
